# ratelimitd

gRPC service in Go: buf v2 for protos, hand-written interceptors (`log/slog`, no middleware framework), health + reflection.
Module `github.com/crowbett/ratelimitd`. Global Go conventions from `~/.claude/CLAUDE.md` apply; this file is only what is specific here.

## Layout
- `proto/echo/v1/echo.proto` - the API. `buf lint` (STANDARD) + `buf breaking` against `main` gate every change.
- `gen/echo/v1/*.pb.go` - GENERATED by `task gen` (buf + local protoc-gen-go/-go-grpc), COMMITTED, never hand-edited.
  A hookify rule blocks Write/Edit under `gen/`. CI fails if `buf generate` produces a diff.
- `cmd/server/main.go` - `grpc.NewServer` with the interceptor chain, health, reflection, keepalive, graceful stop.
- `cmd/client/main.go` - smoke client: health check + `Echo` + `EchoStream`; one `flag` per RPC input.
- `internal/interceptor/` - `Recover` -> `RequestID` -> `Logging` (unary + stream variants, outermost first).
- `internal/server/echo.go` - `EchoServer` (embeds `Unimplemented*`), `Register(grpc.ServiceRegistrar)`;
  `echo_test.go` - bufconn server with the production chain, table-driven per RPC.

## Commands (Taskfile.yml)
- `task gen` (`buf generate`), `task lint` (`buf lint` + `golangci-lint run ./...`), `task lint:breaking`, `task fmt`
- `task test` (`go test -race -count=1 ./...`, needs a C compiler) or `task test:fast`; `task vet`; `task check`
- `task run` (server on :50051), `task client -- -msg hi -count 3`, `task build` (-> `bin/server`), `task docker:build`

## Conventions specific to this repo
- Schema first: edit `proto/`, run `task gen`, then implement. Never edit `gen/`; if it looks wrong, fix the proto or the plugin pins.
- Errors leave handlers as `status.Error(codes.X, ...)`; validate inputs up front (`InvalidArgument`); bound streams (`MaxStreamCount`).
- Streams check `stream.Context().Err()` per send so cancellation returns `Canceled`, never a hang.
- Request id comes from `interceptor.RequestIDFrom(ctx)`; log through the chain, no per-handler loggers.
- Every RPC has a table test in `internal/server/*_test.go` over bufconn (ok, invalid input, cancel where streaming). `/add-rpc` wires all of it.
- Proto changes must pass `buf breaking`; renumbering or retyping a field means a new field, not an edit.

## Definition of done
`buf lint`, `buf generate` is a no-op (`git status --porcelain gen/` empty), `go vet ./...`, `go test -race -count=1 ./...`
(or `task test:fast` if no C compiler, say which), `golangci-lint run ./...` all green. `/go-test` and `/go-lint` run the Go side.
