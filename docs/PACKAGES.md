# Package layout

Moved verbatim from CLAUDE.md. See [../CLAUDE.md](../CLAUDE.md) for the short invariant list.

- `proto/ratelimit/v1/ratelimit.proto` - RateLimitService (Check, BatchCheck) + AdminService (policy CRUD, ResetKey, Stats).
  `buf lint` (STANDARD) + `buf breaking` against `main`. `gen/ratelimit/v1/` is GENERATED by `task gen`, COMMITTED, never
  hand-edited (CI diffs `buf generate`).
- `internal/limit/` - DOMAIN, stdlib only: `Algorithm`, `Params` (+`NewParams`), `Decision`, `Strictest`, `Limiter`/`Store`
  ports, `Req`, sentinels, `Key`/`HashTag`.
- `internal/algo/{gcra,tokenbucket,slidingwindow}/` - pure `Step(state, Params, cost, nowUS)` reference models + `TTL` + an
  in-process `Limiter`. No alloc, no I/O, no floats, no `time.Time` inside.
- `internal/store/local/` (256 shards, ONE sweeper goroutine, `Scale(div)` degraded view), `internal/store/redisx/`
  (go-redis, embedded Lua under `lua/` loaded as a Redis Function - FCALL, EVALSHA on Redis 6 - with a singleflight reload on
  "Function not found"/NOSCRIPT, `Lease`, `Skew`), `internal/store/fallback/` (breaker + modes), `internal/store/lease/` (shared
  policies: per-node leased budget in front of the fallback store; the daemon's outermost `limit.Store`).
- `internal/policy/` - YAML schema (`Set`/`Tenant`/`Policy`), strict `Parse`, `Validate`, `Registry` (atomic snapshot,
  `Watch` mtime poll, `Upsert`/`Delete` file rewrite, `Resolve` hot path).
- `internal/server/` (gRPC adapters + `ToStatus`), `internal/httpapi/` (`POST /v1/check`, same converters),
  `internal/admin/` (`Snapshot` atomics -> `/metrics` text + `/admin/stats`, `/healthz`, `/readyz`), `internal/obs/` (OTel).
- `internal/config/` - env `Load()`/joined `Validate()`; every knob is in the PLAN env table. `internal/bench/` - open-loop
  load harness. `internal/testproxy/` - TCP blackhole/delay proxy for the partition test. `internal/interceptor/` - Recover ->
  RequestID -> Logging.
- `pkg/ratelimit/` - PUBLIC: `Client`, `Dial`, `Embedded`, `Middleware` (RateLimit-* headers, 429), gRPC interceptors.
- `cmd/ratelimitd/main.go` - wiring + three-stage teardown only. `cmd/ratelimitctl/` - CLI (`health | check | policy | reset | bench`).
- `cmd/webdemo/` - js/wasm bridge for the browser demo on crowbett.github.io: one `race` call drives the three algorithms' `Step` over seeded traffic. Logic in `handler.go` (tested natively); `main.go` is `js && wasm` only.
